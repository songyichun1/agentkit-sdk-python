# AgentKit 模型网关快速开始指南

模型网关提供统一的模型访问调用入口。您可以将火山方舟等模型服务配置为供应商，再创建消费者获取访问密钥，最后通过模型网关的 `/chat/completions` 接口调用模型。

本文以火山方舟 `doubao-seed-evolving` 为例。

## 准备工作

请先完成 AgentKit CLI 安装，并配置火山引擎 AK/SK：

```bash
export VOLCENGINE_ACCESS_KEY=<your_access_key>
export VOLCENGINE_SECRET_KEY=<your_secret_key>
```

## 1. 激活模型网关

执行 `activate` 创建或复用当前账号下的模型网关。是否传入 `--apig-gateway-id` 决定模型网关类型：

- 不传 `--apig-gateway-id`：创建共享型模型网关，适合快速启动和体验。
- 传入 `--apig-gateway-id`：创建标准型模型网关，适合需要 VPC 内私网访问、自定义入站/出站网络规格，或对稳定性要求更高的生产场景。

快速启动可以直接创建共享型模型网关：

```bash
agentkit model-gateway activate
```

如果需要标准型模型网关，请先准备 API 网关实例 ID，再执行：

```bash
agentkit model-gateway activate --apig-gateway-id <your_apig_gateway_id>
```

如果已存在模型网关，CLI 会直接提示已存在，并展示 `ModelGatewayId` 和当前状态。只有状态为 `Running` 时，后续配置和调用才可正常进行。

## 2. 添加火山方舟供应商

使用火山方舟 OpenAI Compatible 接口作为供应商：

```bash
agentkit model-gateway provider add \
  --name quickstart \
  --base-url https://ark.cn-beijing.volces.com/api/v3 \
  --api-keys <your_ark_api_key> \
  --models doubao-seed-evolving
```

说明：

- `--name quickstart` 是供应商名称，后续消费者授权会用到。
- `--base-url` 是火山方舟 OpenAI Compatible Base URL。
- `--api-keys` 传入火山方舟 API Key。
- `--models` 配置该供应商支持的模型名。
- `--protocol` 默认使用 `openai`，通常无需显式传入。

供应商创建是异步操作。命令执行后 CLI 会等待模型网关回到 `Running` 状态。

## 3. 查看供应商

通过 `provider show` 确认供应商配置，重点检查 `Access URL`、`Base URL` 和 `Models`：

```bash
agentkit model-gateway provider show --name quickstart
```

输出会逐行展示。调用模型网关时使用 `Access URL`，它是模型网关代理后的访问地址；`Base URL` 是供应商真实地址。

```text
Provider ID: p-ab*******************uv
Name: quickstart
Access URL: https://sab****************uv.apigateway-cn-beijing.volceapi.com/p-ab*******************uv
Base URL: https://ark.cn-beijing.volces.com/api/v3
API Keys: 01******-****-****-****-**********ef
Models: doubao-seed-evolving
```

## 4. 创建消费者

创建消费者，并授权它访问 `ark` 供应商下的所有模型：

```bash
agentkit model-gateway consumer add \
  --name quickstart \
  --allow-models quickstart
```

如果只想授权单个模型，也可以写成：

```bash
agentkit model-gateway consumer add \
  --name quickstart \
  --allow-models quickstart/doubao-seed-evolving
```

消费者创建同样是异步操作。命令执行后 CLI 会等待模型网关回到 `Running` 状态。

## 5. 查看消费者密钥

通过 `consumer show` 获取消费者的 API Key：

```bash
agentkit model-gateway consumer show --name quickstart
```

输出会逐行展示。调用模型网关时使用 `API Keys` 中的密钥。

```text
Consumer ID: c-ab*******************uv
Name: quickstart
API Keys: sk-01****************************ef
Authorization: quickstart:*
TPM:
TPD:
```

## 6. 调用模型网关

获取模型网关的 `Access URL` 后，调用 `/chat/completions`。访问地址通常是模型网关绑定的 API 网关域名。

```bash
curl "<access_url_from_provider>/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <api_key_from_consumer>" \
  -d '{
    "model": "doubao-seed-evolving",
    "messages": [
      {
        "role": "user",
        "content": "你是谁？"
      }
    ]
  }'
```

如果配置正确，模型网关会将请求转发到火山方舟，并返回响应。
